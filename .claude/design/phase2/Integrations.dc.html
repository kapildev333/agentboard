Integrations

Any agent can open the board or spawn a console: a command, an MCP server, or a plugin. All three read the port and token from ~/.agentboard/daemon.json.

The command

on PATH · 0.2.0

Every subcommand starts the daemon if none answers and prints JSON, so shell scripts and agents can parse it.

agentboard open [path]Open a repo as a board; focuses an existing tab
agentboard spawn <agent>--worktree name --prompt text --title
agentboard note <text>Sticky beside the calling console
agentboard statusEvery console with its state, as JSON
agentboard mcpThe MCP server over stdio
$ agentboard spawn opencode --worktree feat-x --prompt "add tests"
{
  "id": "c_8f2a",
  "worktree": ".worktrees/feat-x",
  "branch": "feat-x",
  "placedBeside": "c_41be"   // the caller's console
}
