3 · Data model

Orders are the aggregate root. Everything money-related hangs off a LineItem, and tax is never stored on the order total: it is recomputed from TaxLine rows so that rounding is reproducible per line.

3.1 Order

An Order carries the customer, a shipping Address, a currency and a status. Postal codes are validated by validatePostal(country, code) before the address is accepted, and stored as entered — the autocomplete component formats for display only.

3.2 LineItem and TaxLine

Each LineItem owns one or more TaxLines. Amounts are integers in minor units. Rounding is half-even and applied per tax line, because the accounting export (Xero) rejects invoices whose line taxes do not sum to the total.

The rule lives in src/tax/round.ts as roundHalfEven(value, 2), replacing the earlier Math.round, which drifted by a cent on CAD orders with 13% HST
